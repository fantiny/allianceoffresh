# 生鲜联盟销售数据报表与轻量进销存系统 — 产品需求文档

## 1. 项目背景

重庆集采联盟（生鲜批发配送）目前使用 Excel《每日交易金额汇总表》记录销售配送、报价、收款与退货。本系统将 Excel 数据结构化入库，提供多维度经营报表与轻量进销存能力，支持 Excel 双向导入导出及一键部署。

## 3. 功能需求

### 3.1 数据导入导出（标准能力）

- **Excel 导入**：上传 `.xlsx`，解析工作表「联盟销售统计」「报价表」「商品名别称」「基础定义表」
- **导入模式**：覆盖 / 追加；记录 `import_batches` 与行级警告
- **Excel 导出**：按筛选条件导出销售明细、报价、报表结果（多 Sheet）
- **全库备份导出**：一键导出当前数据库内容为标准 Excel 模板格式

### 3.2 主数据管理

- 客户、商品、商品别称、交易场所、付款状态
- 报价表按日维护

### 3.3 销售业务

- 销售明细列表：按日期、客户、商品、场所、付款状态筛选
- 单条编辑/删除（纠错）

### 3.4 进销存（简化）

- **进**：采购单 + 采购明细（手工录入，Excel 无来源）
- **存**：库存流水（采购入库、销售出库、退货入库、调整）；销售导入可选自动生成流水
- **销**：来自 Excel 销售明细

### 3.5 报表（8 类，均支持 Excel 导出）

1. **经营总览** — KPI：开单金额、结算金额、未收款、退货率；日趋势、付款占比
2. **销售日报** — 按配送日期汇总金额与笔数
3. **客户分析** — 客户排行、应收、退货
4. **商品分析** — 销量、金额、退货（可排除框子押金）
5. **场所分析** — G1 / A2 等对比
6. **收款分析** — 已付/未付、未收款明细
7. **报价对比** — 双福价 / 集采价 / 会员价趋势
8. **进销存简表** — 期初 + 采购 - 销售 + 退货 = 期末

### 3.6 全局筛选

所有报表支持：日期范围、客户、商品、交易场所、付款状态。

## 4. 非功能需求

- 响应时间：报表查询 < 3s（万级明细内）
- 数据精度：金额使用 Decimal，避免浮点误差
- 部署：Docker 本地一键启动；可选 Vercel + PostgreSQL
- 浏览器：Chrome / Edge / Safari 最新两个大版本

## 5. 不在范围（首期）

- 多公司账套、审批工作流、财务对账
- 移动端原生 App
- PDF 导出（二期）

## 6. 验收标准

- 样例 Excel 导入后结算金额合计与源表一致（约 ¥142,058.71）
- 未结款率、退货率与「客户别」透视偏差 < 0.1%
- `docker compose up` 后可完成导入 → 报表 → 导出全流程
